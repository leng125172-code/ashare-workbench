# 0.18.1 失败归档与精确恢复

修复record_failure构造完整归档却漏写磁盘，随后错误提交终态索引的问题。现在先保存不可变提交意图、写入并读回完整归档，再保存终态索引及报告动作。归档失败不会丢弃仍活动的研究；同键同参重试及重启沿用首次报告时刻，状态版本改变时拒绝覆盖。

增加正式的failure_archive_preview/recover，限定当前模式、确切失败批次、原生不可变run_record、当前版本及行业/归属/判断数、配置/判断/历史上下文摘要。逐页核对全部候选后明确选择引用，不从SHA排序猜时间。只恢复缺失档及索引范围，保留失败状态、原时效、账户、计划和外部动作。原报告正文未落盘时明确标为根据原生索引重建。涉及无法确定的旧计划快照、不同已有归档、模式/版本/摘要不符及损坏原生记录均拒绝。

## 验证

- 7项针对性测试与249项全回归通过，覆盖写档/根索引写失败、重启及稳定键、120行业原判断恢复、不同档拒绝、损坏原生记录、模式隔离和协议2历史过期指纹。
- 真实DSH 0.2.1-rc.5 SDK注册17个工具、参数校验及隔离模拟PNG导出通过；未修改活动profile，没有模型请求。此验收不代替真实调度/微信送达。
- Cindy Forge对0.18.1校验打包通过。生产恢复另由正式接口执行并读回核对，不用合成资料修补真实研究。

失败归档恢复不使跨日研究变成当前有效分析，不跳过证据时效，不创建交易或收益记录。真实账户、运行身份及原始恢复回执只保存在私有验证目录。
