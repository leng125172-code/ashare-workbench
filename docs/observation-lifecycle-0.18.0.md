# 0.18.0 研究阶段与停复牌观察

行业成员、价值分档后的投资候选、停牌观察分别展示。价值分档不等于可以买入。主源缺失或过期报价按股票身份请求备用源，保留原因及来源；无效旧价只留在lastKnownQuote，不填充当前报价。

结构化停复牌事件须匹配同股票资料包的官方公告URL、准确发布时间、实际正文指纹和独立互核。已知停牌、未解决分歧及尚未完成复牌重新评估的股票禁止正权重配置。模式独立的事件账本跨轮/重启继承原时间与指纹；新增复核单调合并，不能被旧副本删除。活动研究和每日扫描双向传播事件，旧判断失效，提交前重算检查。冻结报告不追溯改写。

复牌后须有有效证据、后续有效报价和新分析。证据时效仍生效；旧复牌核验过期会重新要求核验，不作为永久可交易证明。无报价本身不确认停牌，停牌观察也不宣称此前已经值得买。

## 实际验证

- 242项完整Node测试通过，包含跨轮重启、scan→run及run→scan更新、冲突不回滚、同时间相反事件、正权重阻断、旧价隔离及备用源失败。
- 实际安装的DSH 0.2.1-rc.5 SDK注册17个工具并通过隔离调用、参数校验与模拟PNG导出；未修改活动profile，未调用模型。此结果不等于DSH微信/原生定时调度端到端验收。
- 真正Chrome隔离profile加载实际页面及脚本、合成请求数据，在320px浅/深模式通过28项界面检查，含停牌观察、候选标签和空资料提示；无横向溢出。
- Cindy原实例原位更新0.18.0后get_state与派工只读查询成功，配置、研究进度、既有报告及待办动作与更新前一致。测试不向真实资料写合成停复牌事件，不交易，不创建模拟成交。

公开仓库不包含真实研究批次、账户、会话身份或本机运行快照。完整运维回执保存在私有验证目录。
