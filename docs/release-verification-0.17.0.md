## 已知边界

- 历史重置不是安全擦除，SQLite文件可能保留可复用空间；库外备份明确保留。
- dsh真实原生计时触发、独立微信通道和外部发送尚未端到端验收。DSH没有同等原生pause、pre-run-hook和expireAt接口，能力差异见[dsh说明](../dsh/README.md)。无连接或不支持时保留待办，不伪造成功。
- npm发布当前受账号/访问条件影响，尚未发布；社区插件中心收录也尚未完成。
- 没有执行真实交易。合成测试图和测试收益不证明真实投资表现。
