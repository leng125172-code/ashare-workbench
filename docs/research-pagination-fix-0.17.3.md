# 0.17.3 行业分页完整性修复

旧分页把可技术评分成员与K线未就绪成员合并。有K线、但报价缺失的成员两边都不满足，会从派工输入消失；完整性校验仍要求读完全部成员，因此正确拒绝少读的提交。一次真实研究中表现为414个成员只返回412条。

协议1、协议2派工页和普通行业页现在使用同一完整成员分区：可评分成员按原规则排列，其余成员全部保留；缺报价不补成0、不制造技术分档，也不放宽提交完整性校验。只读排序不改变研究输入token或改写历史判断。更新后受影响任务必须实际补读、复核，不能仅修改读数重用旧结论。

本版同时保留腾讯科创板报文的原始成交量；单位未确认时标准化volume为null并返回unknown说明，不套用主板换算。历史报价快照不自动回填。

验证于2026-11-06：

- 227项自动测试通过；新增混合报价/全缺报价、协议1/2、多页/唯一成员数、未分档汇总、重启token稳定、少读拒绝和完整读取接收的回归检查。
- 真实DSH SDK注册17项工具及模拟PNG导出通过；不代表原生计时/微信已验收。
- 本机Cindy原位升级0.17.3，真实受影响行业按100/100/100/100/14分页返回414个唯一成员，先前遗漏的两条缺报价记录均保留。
- 升级及只读复核前后，插件revision、账户配置、研究进度、活动计划不变。

安装验收不等于市场审核或npm发布。完整账户和原生回执只存于私有验证目录，未进入公开仓库。
