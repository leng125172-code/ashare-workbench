# 0.18.2 旧分片失败归档恢复

补充真实旧分片格式的只读库存与正式缺档恢复。来源只接受最多128片的有序原生引用，逐片核对路径摘要/编码/逻辑字节及整状态SHA、字节数、源版本，进一步核对行业唯一标识、股票归属键、完整判断、配置及历史上下文。不会接收调用方的研究正文。

恢复先以规范manifest摘要计算路径，在原库固定顶层原格式清单并raw读回，保证既有分片受到清理保护；然后写入、读回归档，最后只补当前失败索引的范围和来源。预览token绑定根、来源和证明，源清单新增不会破坏同键重试。不回滚整份旧状态，不改变当前账户、计划或外部回执；历史分析/监管时间不续期，报告重建有明确标记。
