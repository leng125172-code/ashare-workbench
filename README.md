# A股投研工作台

明确研究范围、保留原文证据和实际回执的 A 股投研插件。提供行业四组、股票三档、风险约束下的建议配置、版本化计划与复查流程。**仅研究建议，无券商连接或自动交易。**

## 首步：选择倾向行业

在账户配置中选择一种研究范围：

- **成交额前120**：读取行业目录及成交额，按金额降序取前120个，同额按行业ID排序。目录或成交额不完整时不伪造排名，也不降级成全行业采集。来源不足120项时按真实数量展示。
- **手动选择**：按名称或 BK 代码搜索、多选行业。至少选择一个；空选择不会扩大范围。旧版已保存的行业ID迁移为手动模式。

先读取的是行业目录摘要，确认范围后才抓取所选行业的成分股、日K和资讯。账户页面展示成交额、排名、来源和行情/读取时间。来源目录可能包含重叠层级，120个板块不等于120个互不重叠的行业；热度也不代表投资价值。

## 两个平台

| 平台 | 入口与数据 | 已知边界 |
| --- | --- | --- |
| Cindy | `plugin/ghost.json`；独立工作台和账户表单；`/ashare-research` 参考技能 | 调度和微信须通过宿主真实能力执行并记录回执。市场审核、安装和发送是不同状态。 |
| DeepSeek Harness | 根 npm 包的 `./dsh` 入口；`ashare_*` 工具；独立 profile 资料 | 不共享 Cindy 数据或微信授权。账户通过工具配置；通道或原生调度能力不足时保留待办，不伪造成功。 |

本次适配验证目标：Cindy **0.1.125**，DeepSeek Harness **0.2.1-rc.5**。安装后的实际服务能力仍以宿主返回为准。

## 使用 Cindy

从 Cindy 插件市场搜索“A股投研”，或者使用开发工具打包/安装 `plugin/`。打开账户配置，填写自己的现金、实际持仓、风险约束、期限、倾向行业和研究伙伴。配置保存不会自动研究或发送消息。

在有对应权限的 Cindy 会话执行：

```text
/ashare-research mode=live，使用已保存的账户和倾向行业研究。
仅提供建议；按实际证据给出四组、三档与不足项，核对计划、原生调度和微信回执。
```

若需要微信报告，在 Cindy 自己的连接界面完成绑定并向 ClawBot 发送普通消息。插件不保存联系人凭据，不替换收件人，也不从其它平台复制令牌。

## 使用 DeepSeek Harness

发布后的 npm 包名为 `dsh-plugin-ashare-workbench`；源码中包含 `dsh/cordis.patch.yml`。npm 包发布、社区审核与真正出现在插件中心需分别核对，源码仓库公开不代表已经上架。

```sh
dsh plugin --profile web add dsh-plugin-ashare-workbench@0.17.0
```

开发安装及工具/通道能力详见 [dsh 适配说明](dsh/README.md)。使用 `ashare_get_research(view:industry_catalog)` 查看范围，通过 `ashare_configure` 保存本平台账户，再按 `ashare_begin_research` → 分批采集 → 原文互核 → 只读行业分工 → 主代理保存/定稿推进。不要把模拟默认账户复制成真实资金。

## 证据、增量分析与维护

多行业研究使用当前引擎真实子代理，每行业一个只读任务，默认最多3并行，其他排队。行业结果由主代理串行保存；配仓、定稿、调度和消息也由主代理执行。无法派工时明确降级。

同日增量协议把行业快照与定稿前的最新市场复核分开：未变化行业保留，关联证据变化或到期的行业须重新分析。旧 worker 不能只换 token 复用。保留最新上下文2小时、监管查询1小时、正文双审、最新完整交易日日K和正权重报价门禁。跨日旧基线不会通过改时间续期。

证据不足单独列出，不归入“不推荐”、不凑股票分档或正仓位。空仓等待可以是有效建议。有限范围监管零记录不能证明无风险。

历史重置必须先获得用户明确要求、停止研究并核对本计划原生任务、在库外备份。`reset_history_preview` 只读预览；`reset_history` 校验版本和快照后按当前模式清理，保留账户配置并支持同键恢复。`live` 和 `simulation` 分开，历史重置不自动取消宿主调度。SQLite行已删除不保证物理文件立即缩小。

## 开发与验证

需要 Node.js 22.22 或更新版本。Cindy 核心测试不依赖外网行情或 npm 依赖，也不访问用户资料。DSH 测试需要本机已安装兼容 DSH 及其真实 SDK，见适配说明；完整环境可运行 npm test。

```sh
npm run test:cindy
```

窄屏账户表单的可重复检查见 [界面测试说明](docs/industry-preferences-ui-testing.md)。dsh 的 SDK/运行时测试见其适配说明。测试数据、公开来源与脱敏记录位于 `tests/fixtures/`。

目录：`plugin/` Cindy 插件及共享业务模块；`dsh/` 平台适配；`skill/` Cindy 工作流参考；`tests/` 离线与集成验收；`scripts/` 通用历史研究算法。运行数据、账户、备份和包产物不进入 Git。
